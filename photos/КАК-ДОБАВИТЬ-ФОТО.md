# Фотографии шахматистов

Снимки в приложение не входят: на большинство есть авторские права.
Подстановка готова — нужно только положить файлы.

## Как добавить

1. Положи снимок в эту папку. Имя файла — фамилия латиницей, строчными,
   без пробелов: `kasparov.jpg`, `carlsen.jpg`, `ding.jpg`.
2. Впиши имя файла в `index.json`:

```json
{ "files": ["kasparov.jpg", "carlsen.jpg"] }
```

3. Всё. Фотография появится на обложке матча и на карточке игрока.
   У кого фото нет — останется рисованная обложка.

## Что подходит

- Формат `.jpg`, портрет, лицо крупно, не меньше 600 пикселей по короткой
  стороне. Обложка обрежет снимок по вертикали 300 × 420.
- Права: годятся собственные снимки, фотографии из общественного достояния
  (Стейниц, Ласкер, Капабланка, Алехин ранних лет) и всё, на что у тебя есть
  разрешение. Снимки из интернета «просто так» брать нельзя — за них приходят
  претензии, особенно если приложение попадёт в магазины.
