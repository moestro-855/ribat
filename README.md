# Рибат — пробная версия

Шахматный инструмент тренера: задачи по темам и уровням, архив турниров с
таблицами и партиями, личные архивы игроков, игра с движком и разбор.

Здесь лежит **собранный сайт**, а не исходник. Приложение статическое —
ничего серверного ему не нужно, — поэтому GitHub Pages раздаёт эту папку как
есть. Исходник и сборочные скрипты живут отдельно.

## Как обновить

В папке с исходником:

```bash
npm run build
python pipeline/deploy_site.py --push
```

Скрипт переносит свежую сборку сюда (не трогая `.git`), выбрасывает
оригиналы снимков и делает коммит с отправкой.

## Что внутри

    data/         задачи, справочник турниров, партии, личные архивы
    photos/       портреты игроков
    tourcovers/   обложки турниров
    citycovers/   виды городов
    engine/       движок (WebAssembly)

## Телеграм

Приложение открывается и по обычному адресу, и кнопкой бота
[@ribat64_bot](https://t.me/ribat64_bot). Внутри Телеграма подключается
`telegram.js`: он просит окно во весь экран и отключает свайп вниз, иначе
приложение висит на половине высоты и закрывается посреди партии.

## Оговорка

Это пробная выкладка для проверки на телефоне, не публикация базы.
